# 恋爱依恋类型测试 💗

基于 **ECR-R 量表**（Experiences in Close Relationships–Revised）编制的中文参考自评 H5，帮助你了解自己在亲密关系中的两个连续倾向：**依恋焦虑** 与 **回避亲密**。

**在线体验**：<https://attachment-love-test-20qe.zai.site>

## ✨ 特点

- 📋 **36 题完整版**：采用 ECR-R 官方 36 题（焦虑 18 题 + 回避 18 题）的中文参考译文，官方题序
- 🎚️ **7 级计分**：每题附完整文字标签（完全不符合 ~ 完全符合），支持键盘 1–7 与方向键作答
- 📊 **连续分数**：结果为两个维度的均分（1–7）+ 四分区示意图；**中点 4 仅作图示参考，不是类型分界线**
- 🎨 **四种倾向解读**：偏安全 / 偏焦虑-痴迷 / 偏疏离-回避 / 焦虑与回避均较高，含情境对照与沟通练习
- 🖼️ **分享卡片**：Canvas 生成 1080×1620 竖版卡片，长按即可保存
- 🔒 **隐私友好**：无后端、无埋点，答案只存在你自己的浏览器里，可随时一键清除
- ♿ **无障碍**：键盘完整操作、aria 标注、焦点管理、`prefers-reduced-motion` 适配

## 🔬 学术依据与声明

- 题目与计分键来自 Fraley, Waller, & Brennan (2000) 公布的 ECR-R 官方题集（[作者说明页](https://labs.psychology.illinois.edu/~rcfraley/measures/ecrr.htm)），按官方规则处理反向计分题并取两维度均分
- 中文措辞为**参考译文**，尚未经过独立信效度验证
- 依恋在学术上是**连续维度**而非离散盒子：本页四分区仅帮助理解，不构成类型判定
- 本测试仅供自我探索，**不构成心理诊断**，也不是择偶或关系去留的依据

## 📦 本地使用

**方式一（最简单）**：双击打开 `依恋类型测试.html`——CSS/JS 全部内联的单文件版，离线可用。

**方式二**：在本目录起一个静态服务后访问 `index.html`，例如：

```bash
python -m http.server 8765
# 或
npx serve .
```

## 🛠️ 构建

修改 `index.html / css / js` 源码后，重新生成单文件版：

```bash
node build-singlefile.js   # 输出 依恋类型测试.html
```

`extract-parts.js` 用于反向操作：从单文件 HTML 中提取回 `css / js / index.html` 源码（先手改单文件再同步源码时用）。

## 📁 目录结构

```
├── index.html            # 页面结构（多文件版入口）
├── css/style.css         # 全部样式
├── js/
│   ├── data-questions.js # 36 题题库（维度归属 + 反向计分标记）
│   ├── data-results.js   # 四种倾向的内容数据
│   └── app.js            # 状态、计分、渲染、分享卡片
├── 依恋类型测试.html      # 单文件离线版（构建产物）
├── build-singlefile.js   # 单文件打包脚本
└── extract-parts.js      # 单文件 → 源码 反向提取脚本
```
